# Business Sales Performance Analytics

## Project Overview
This project analyzes business sales data to identify:
- Revenue trends
- Top-selling products
- Regional sales performance
- Monthly sales patterns

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights
- Technology category generated highest sales
- Phones and Chairs were top-performing sub-categories
- West region showed strong sales performance
- Monthly trends revealed seasonal demand fluctuations
